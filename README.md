\# Feature 09 - Customer Reports



\## Description

This feature provides customer-related reports for the Partpurja Management System.



\## Implemented Functionalities

\- View top spending customers

\- View regular customers

\- View overdue credit customers



\## API Endpoints

\- GET /api/customer-reports/top-spenders

\- GET /api/customer-reports/regular-customers

\- GET /api/customer-reports/overdue-credits



\## Testing

The endpoints were tested using Postman and returned successful JSON responses.
