\# Feature 08 - Customer History \& Vehicle Information



\## Description

This feature manages customer records and associated vehicle information.



\## Implemented Functionalities

\- Register customers

\- Store vehicle details

\- Retrieve customer information

\- Retrieve customer by ID



\## API Endpoints

\- GET /api/customers

\- POST /api/customers

\- GET /api/customers/1



\## Testing

The endpoints were tested using Postman and returned successful JSON responses.
